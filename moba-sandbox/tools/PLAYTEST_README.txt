MOBA SANDBOX — PLAYTEST BUILD
=============================

Thanks for playtesting! This build can record your games so they can be
analysed afterwards.

0. EXTRACT THE ZIP FIRST (right-click -> Extract All). Running the game
   straight from inside the zip saves the logs to a temporary folder that
   Windows deletes.
1. Run "MOBA Sandbox (playtest).exe". If Windows says "Windows protected
   your PC", click "More info" -> "Run anyway" (the exe isn't signed).
2. On the hero-pick screen, click "Play log: OFF" so it says ON.
   A red "PLAY LOG" in the top-right corner means it's recording.
   It stays on next time you start the game.
3. Play as many runs as you like.
4. When you're done, zip the "playlogs" folder that appears next to the
   exe and send it back. That's it.

Controls and how a run works: see HOW_TO_PLAY.txt.
