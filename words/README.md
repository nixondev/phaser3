# words/ — all player-facing writing

Every piece of prose the player reads lives here as Twee 3 plain text
(`.twee` files). Passage name = global key; creating a file is all the
registration there is.

**Full documentation: [`WORDS.md`](../WORDS.md) at the project root** —
format rules, key namespaces, `words:` references, branching syntax,
Twine round-trip, and the add-writing checklist.

Quick taste:

```twee
:: thoughts/protag-house-first [thought]
Three days since the sirens stopped.
Nobody came for us. Nobody is coming.
```
